# RT - Assignments Overview

This repository contains the two assignments of the course Research Track I:
1. **Turtlesim Simulation** <br>
   two nodes that control two turtles in turtlesim and prevent collisions between them and with the borders. 
   
2.   **Gazebo Simulation** <br>
    two nodes and two services that control a robot to move in a space with obstacles without collide with them.

Each assignment is organized in its own dedicated folder and its own README with the own specifications.
